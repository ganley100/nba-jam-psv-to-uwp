# UWP app (Xbox Dev Mode)

Minimal shell that links `so_util_win` and runs on Xbox Series X|S Developer Mode.

## Layout

```
uwp/
  Package.appxmanifest
  NbaJamLoader.vcxproj
  src/main.cpp
  Assets/          (generated by CI)
```

## Build via GitHub Actions

1. Push to `xbox-uwp` or run the **UWP Build** workflow manually.
2. Download the `NbaJamLoader` artifact.
3. On the Xbox (Dev Mode Device Portal):
   - Install the `.cer` first (Settings → Security / or via portal).
   - Add the `.appx` + the files under `Dependencies\x64`.
4. Launch **NBA Jam Loader**. Status text appears on screen; log is also written to
   `LocalState\loader_log.txt` (readable from Device Portal → File explorer).

## Local build (Visual Studio)

Open `uwp\NbaJamLoader.vcxproj` in VS 2022 with the UWP / Windows 10 SDK workload.
Create the five PNGs under `uwp\Assets\` (or copy from a CI artifact), then Build → Deploy.

## What works today

- App launches on Xbox / Windows
- `so_util_win` is compiled into the binary
- Memory limits are printed
